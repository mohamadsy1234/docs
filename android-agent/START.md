# البدء: تشغيل الوكيل على هاتفك (MVP-1، وضع الظل)

ثلاث قطع تعمل معاً على الهاتف نفسه:

| القطعة | أين | الدور |
| --- | --- | --- |
| **Agent Bridge** | تطبيق أندرويد | يلتقط رسائل واتساب، ويعرض اقتراح الرد في إشعار، ويرسله فقط بنقرتك بعد فتح القفل |
| **الوكيل** | Termux | يستقبل الرسائل ويعدّ الاقتراحات |
| **لوحة NEXUS** | متصفح الهاتف | تراقب كل شيء حياً، وفيها زر إيقاف الطوارئ |

> **المرحلة الحالية:** الوكيل يقترح نصاً تجريبياً ثابتاً للتحقق من المسار كاملاً. ربط LLM الحقيقي هو الخطوة التالية.

## 1. Termux (مرة واحدة)

ثبّت Termux وTermux:API من F-Droid، ثم:

```bash
pkg update && pkg upgrade -y
pkg install -y python git termux-api
pip install websockets

git clone --depth 1 --filter=blob:none --sparse \
  -b layer-2-python-brain https://github.com/mohamadsy1234/docs agent-repo
cd agent-repo && git sparse-checkout set android-agent
```

## 2. تطبيق Agent Bridge (مرة واحدة)

1. ابنِه من مجلد `android-agent/bridge` في Android Studio (التفاصيل في [bridge/README.md](bridge/README.md)) وثبّته.
2. افتحه وانقر **نسخ** لنسخ المفتاح السري.
3. في Termux:

   ```bash
   mkdir -p ~/.config/agent
   termux-clipboard-get > ~/.config/agent/.env
   chmod 600 ~/.config/agent/.env
   ```

4. في التطبيق: فعّل **الموافقة**، ثم **منح صلاحية قراءة الإشعارات**، ثم **السماح بعرض الإشعارات**.

## 3. التشغيل (كل مرة)

```bash
cd ~/agent-repo/android-agent/agent
sh start.sh
```

يفحص `start.sh` البيئة، ويبقي المعالج مستيقظاً، ويشغّل الوكيل، ويفتح اللوحة في المتصفح تلقائياً. يتصل Bridge بالوكيل خلال ثوانٍ.

لفتح اللوحة لاحقاً من نافذة Termux أخرى:

```bash
termux-open-url "$(python3 ~/agent-repo/android-agent/agent/agent.py --dashboard-url)"
```

## 4. الاستخدام اليومي

- **تصلك رسالة واتساب:** يظهر إشعار "🤖 اقتراح رد لـ …". انقر **إرسال فوراً** (يطلب فتح القفل إن كان الهاتف مقفلاً) أو **تجاهل**.
- **اللوحة:** تعرض الرسائل الواردة، والاقتراحات، وقراراتك، وزمن كل اقتراح، وسجل الأحداث، وحالة اتصال Bridge.
- **إيقاف الطوارئ (في اللوحة):** يوقف كل الاقتراحات فوراً، ويبقى نافذاً حتى بعد إعادة التشغيل، إلى أن تضغط **استئناف**.

## ما لا تفعله اللوحة، عمداً

- **لا ترسل أي رسالة.** الإرسال من إشعار الهاتف فقط، بعد فتح القفل.
- **لا تعدّل القائمة البيضاء ولا تعليمات الوكيل.** أي تطبيق على الهاتف يستطيع الوصول إلى منافذ `127.0.0.1`، فلو كانت اللوحة تتحكم بذلك لصار ثغرة.
- **رابطها خاص:** يحمل مفتاحاً يتغير مع كل تشغيل، ولا يعمل إلا من الهاتف نفسه. لا تشاركه.

## عند المشاكل

| العَرَض | السبب الأرجح |
| --- | --- |
| `secret_ok=false` | ملف `~/.config/agent/.env` غير موجود، أو صلاحياته ليست 600 |
| `port_free=false` | الوكيل يعمل أصلاً، أو تطبيق آخر يحجز المنفذ 8000 |
| إشعار "خادم غير موثوق على المنفذ 8000" | المفتاح في Termux لا يطابق المفتاح في التطبيق، أو تطبيق آخر ينتحل الوكيل |
| اللوحة تقول "انقطع الاتصال بالوكيل" | أُغلقت نافذة Termux أو قتل أندرويد العملية. انظر [دليل اختبار Termux](agent/TERMUX-RUNBOOK.md) |
| لا يظهر إشعار ظل | تحقق من الموافقة وصلاحية الإشعارات في التطبيق. المجموعات والوسائط تُتجاهل عمداً |
